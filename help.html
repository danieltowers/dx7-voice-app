Browsers

The app sends voices as MIDI System Exclusive messages, through the browser's Web MIDI. Use Chrome or Edge, on Android or on a computer. The browser asks once for permission to control MIDI devices; the app cannot send until it is allowed.

Safari has no Web MIDI, and neither does any browser on an iPhone or iPad: the app opens and browses there but cannot send.

A phone needs a USB-MIDI interface on its USB port (with an OTG adapter if the interface's plug does not fit). Install the app from the browser's menu (Add to home screen, or Install app) and it opens without a network.

Sending a voice

Tap a voice to send it to the edit buffer of every target that is on. Previous and Next step through the list on screen. The status line at the top shows the port in use and the result of the last send.

Memory protect stays on everywhere. Edit-buffer messages bypass it, so nothing stored on an instrument changes.

Editing a voice

Edit opens the controls for the voice last sent. Each move of a slider goes out at once, as a parameter change, to the targets that are on.

An edit lives only in the instruments' edit buffers. Sending any voice replaces it, Reset sends this one again as published, and nothing is saved.

Frequency
coarse moves the ratio in whole steps and keeps fine; fine moves fine across 0 to 99 and keeps coarse; continuous moves both along one rising run. The value shown is the operator's true ratio, or its frequency in Hz when the operator is in fixed-frequency mode. Choosing a setting sends nothing.
Output level
0 to 99. On a carrier it sets that part's volume; on a modulator, how much it colours the operator it feeds.

Setup, per instrument

To check the connection, open the hardware check. It sends one fixed voice to the instruments.

Library

The starter voices are a small library of voices made by the DX7 build agent, fetched from this site when you load them. A library file of your own, voice-library.json, is written by tool/dx7 export-library in the dx7-sound-builder-agent project and copied to this device. Either way, the library loaded last replaces the one kept, and it stays on this device; nothing is sent over the web.

History

Every voice sent, newest first, up to 200. It stays on the device being used to edit the voices.
