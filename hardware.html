Send

The voice only. All three instruments should play BRASS 1.

BRASS 1 renamed "BRASS 1 +A", with a DX7II addendum. On the DX7s and the DX7IID it should play in unison, thick and detuned, and the pitch bend wheel should bend an octave. The TX816 gets the voice only and should play plain BRASS 1.

The library app will send the addendum first, until this check says otherwise.

Trial: a parameter change

Tap Send BRASS 1 above first: the slider changes one parameter of the voice already in each edit buffer, so every instrument must hold BRASS 1. Each new position goes at once, as a parameter change, to the targets that are on; nothing else in the voice changes, and nothing stored.

BRASS 1's own value is 0.50. Operator 1 is a carrier, so the pitch of that part of the sound moves: 1.00 is an octave above 0.50, 2.00 another octave.

For each instrument (the DX7s, the DX7IID, the TX816), write down three things in research/sysex-reception.md:

  1. Accepted: does a new position change the sound (and the display, or the TF1's green Parameter Change LED), or does nothing happen?
  2. Held note or next note: hold a note and move the slider one step. Does the held note change, or only the next note you play?
  3. Fast drag: drag quickly from one end to the other and back, then stop. Any glitch, stuck note or dropped change? Does the sound settle on the value shown? If it does not, try a slower drag and say how slow works.

Hardware checklist

Steps, and what to write down

Write what you find in research/sysex-reception.md, section "Hardware milestone results". Write what you saw, including "nothing happened".

Before you start

  1. Set each instrument as in the setup notes above. Leave memory protect on everywhere: the DX7s, the DX7IID and every TF1.
  2. On each instrument, note the name of one stored voice (internal 1, say). The last step of the chain check calls it up again to show nothing stored changed.

The chain

  1. Open this page from its Pages address in Chrome on the phone. Chrome should ask once to control MIDI devices. Allow it. Reload: it should not ask again.
  2. Plug in the USB-MIDI cable through the OTG adapter. With one output the page uses it and names it on the status line. With several, it shows a chooser. Reload: the choice should still be there.
  3. Tap Send BRASS 1. The DX7s should show BRASS 1 and play it from its own keys. The TF1 modules' green Parameter Change LEDs should flash, and the TX816 should play BRASS 1 from the DX7s keys. The DX7IID should play BRASS 1 from its keys.
  4. On each instrument, call up the stored voice from step 2. It should be unchanged, and memory protect should still be on.

Addendum order (finding 5)

  1. Reset: on the DX7s and the DX7IID, call up a stored voice in plain Poly mode, with no unison.
  2. Tap BRASS 1 +A, addendum first. On each of the DX7s and the DX7IID: does the display say BRASS 1 +A? Does a chord sound in unison, thick and detuned? Does the wheel bend an octave? Write down applied or not applied for each one.
  3. Reset as in step 7, then tap BRASS 1 +A, voice first. Write down the same for each instrument.
  4. Leftover addendum: after a tap that applied the addendum, tap Send BRASS 1 (voice only). Does unison stay on, left over from before, or go? This decides whether the library app must send an INIT addendum with voices that have none.
  5. The order to use: addendum first if that worked, or if both worked; voice first if only that worked. Set ADDENDUM_FIRST in app/send.js to match and republish.

Addendum layout

  1. With the addendum applied, read the values in the table above on the DX7s panel, and on the DX7IID if you can. The positions of Yamaha's parameters 64 to 73 come from the repo's transcription of booklet 10, which nobody has checked against the scan. Write down each value you could read, and any that differ. If unison is missing in both orders, the layout may be at fault, not the order.

TX816 and the addendum (finding 12)

  1. While doing steps 8 and 9, watch the TF1 modules. Does an ERROR LED light? Does the green LED flash for the addendum message? Does the TX816 still play plain BRASS 1, with no change to its sound? Write down what each module did.

Optional: Dual mode on the DX7IID (finding 4)

  1. Put the DX7IID in Dual mode and tap Send BRASS 1. Which of A and B changed? Return to Single mode.

If a send does not arrive

  1. If a display does not change, raise the pause to 150 ms and try again. Write down the smallest pause that works.
  2. If a setup note above was wrong, correct it here, in the spec and in the research note.
